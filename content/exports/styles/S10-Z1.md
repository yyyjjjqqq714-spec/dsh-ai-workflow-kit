# Z1 水墨

- 分类：Z 中国风 · 水墨
- 长什么样：生宣白底上大团墨色自然晕开，边缘毛糙、中心焦黑向外渐淡，画面一半以上是空的，只有两三段竹枝和一只飞鸟；全程无彩色，靠墨的五级浓淡分层
- 适合：文化类片头、诗词朗诵背景、茶与香品牌、纪录片章节卡
- 关键词：水墨、晕染、留白、竹枝、墨分五色

## 风格提示词

用代码（Canvas 2D）画一段「水墨」风格的动画，16:9，30fps，7 秒。

画面规则：
- 底色 #f3ede1（生宣白），四角压 6% 的 #d8cdb8 暗角，模拟纸张受潮
- 墨只用一色 #1b1b1b，靠 alpha 分五级：1.0 / 0.75 / 0.5 / 0.3 / 0.12
- 竹枝是 3-5 段折线，节处留一道缺口；竹叶两笔成「个」字，起笔重、收笔尖
- 留白必须占 55% 以上，右下 1/4 不许进任何内容——那块只放落款和朱印
- 墨团边缘不许是圆的：用 60-90 个半径抖动的圆随机叠出毛边

动画节奏：
- 0-2s：第一团大墨从中偏左滴落，半径 0→120 扩散，外圈淡墨同时向外爬
- 2-4.5s：竹枝自上而下生长（每节 0.35s），叶随枝出，叶尖带 0.1s 回弹
- 4.5-6s：右上一只飞鸟掠过，两段折线翅膀在 0.6s 内振 3 次
- 6-7s：右下角落款「水墨」+ 朱印 #a8352b，全画面静止

技术要点：
- 墨团用三层 `radialGradient` 叠加（0 处 alpha 0.9、0.6 处 0.45、1 处 0），每层随机偏移 8px 打破正圆感
- 毛边靠 `ctx.filter = 'blur(6px)'` 画完再错位叠 3 遍，最后一遍不 blur
- 竹叶用 `quadraticCurveTo`，控制点偏出轴线 30%，才有「撇」的力度
