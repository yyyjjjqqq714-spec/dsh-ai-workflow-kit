# Z13 水墨漫画

- 分类：Z 中国风 · 水墨漫画
- 长什么样：毛笔墨线勾出的人物，头大得夸张占身体一半，眼睛是两个带高光的黑豆，嘴巴咧到耳根，额头挂三滴汗；线条有粗细顿挫，配白底黑边的圆气泡，气泡尾巴指向人物，像报纸上的四格漫画
- 适合：知识科普的轻松段落、社交媒体系列短片、教育 App 讲解、品牌人格化 IP
- 关键词：水墨漫画、墨线、夸张表情、对话气泡、幽默

## 风格提示词

用代码（Canvas 2D）画一段「水墨漫画」风格的动画，16:9，30fps，7 秒。

画面规则：
- 纸底 #f6f1e5，人物脚下画一道 3px 的墨线当「地面」，其余留白
- 墨线 #1a1a1a，`lineWidth` 在主轮廓 3px、五官 2px、衣物褶 1.2px 三档
- 人物比例：头高 = 全高的 50%，肩宽 = 头的 0.7 倍，四肢是两条细线，脚是两个小弧
- 表情要夸张：眼是 r=14 的实心椭圆 + 左上白点高光，嘴是宽 46 的弧，嘴角超出脸缘
- 气泡：白 #ffffff 填充、2px 黑边、圆角 26px，尾巴是两根弧线收成一个尖；气泡宽 260-320
- 淡墨 #b9b2a4 只用于脸侧阴影和地面投影，alpha 0.5

动画节奏：
- 0-1.5s：人物从左下「甩」进来，入画时整体倾斜 -8° 再回正
- 1.5-3s：脸部表情切换一次——眼睛放大 1.3 倍，嘴巴由平弧变成大张口
- 3-4.5s：气泡从人物嘴部弹出（scale 0.2→1.06→1，尾巴跟着拉伸）
- 4.5-7s：气泡内文字逐字跳出（每字 0.06s），人物点头两次，汗滴滑落

技术要点：
- 墨线粗细变化：同一批路径先用 `lineWidth 3` 描、再用 `lineWidth 1.2` 描一次，产生「双勾」层次
- 气泡尾巴用 `quadraticCurveTo` 两根曲线在尖点相交，别用三角形，直角会破坏手绘感
- 表情切换不要补间，直接两套参数插值 0.15s 内跳变，漫画感来自「突变」
