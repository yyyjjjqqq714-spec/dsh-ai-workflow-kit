# Z8 敦煌

- 分类：Z 中国风 · 敦煌壁画
- 长什么样：土黄偏赭的泥壁底色上，一个侧身屈腿的飞天凭三条长飘带浮在空中，线条是土红细线，颜色只有石绿、朱砂、白垩几种矿物色；墙面到处是剥落的小洞和噪点，像被风沙磨过一千年
- 适合：文博与考古内容、丝路主题纪录片、国潮美妆包装、文化展览片头
- 关键词：敦煌、飞天、飘带、壁画、斑驳肌理

## 风格提示词

用代码（Canvas 2D）画一段「敦煌」风格的动画，16:9，30fps，8 秒。

画面规则：
- 壁底 #c49a63，上缘压 #a87f4c、下缘压 #8f6a3f 的纵向渐变，模拟墙脚积尘
- 矿物色仅四支：#2f6f66（石绿）、#a63c2c（朱砂）、#8c3b2e（土红）、#ece0c8（白垩）
- 一切轮廓用 #8c3b2e 的 1.5-2px 线，线不闭合、允许断口，像后人补描
- 飞天侧身，两腿一屈一伸，手臂上举托物；身体只填白垩底，局部点石绿
- 飘带三条，从肩后甩出，宽 10px 收到 2px，末端分两三叉，走长 S 曲线
- 斑驳：全画面 300 个随机小洞（半径 1-6）用 `destination-out` 挖穿，边缘再描一圈土红

动画节奏：
- 0-2s：壁底先出，斑驳噪点由 0 渐到满（模拟镜头推近看清肌理）
- 2-4.5s：三条飘带自肩部依次展开，各自以不同相位正弦摆动，振幅 26px
- 4.5-6.5s：飞天整体上浮 30px、缓慢右移，屈腿那只脚踝轻转 8°
- 6.5-8s：上下各压一条 #8c3b2e 装饰带（含联珠圆点串），画面定住

技术要点：
- 飘带用采样点连成多边形（左右各一条边，宽度按 `sin` 收窄），比 `lineWidth` 更能做「渐细」
- 剥落用两层：`destination-out` 挖洞 + 洞缘 `stroke` 土红 alpha 0.35，才有厚度
- 噪点用离屏 canvas 一次性画 2000 个 1px 点做成 pattern，`fillRect` 平铺，比逐帧画点快一个数量级
