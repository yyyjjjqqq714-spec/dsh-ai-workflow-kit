# H5 Broadside

- 分类：H 现成版式 · 报纸版式
- 长什么样：泛黄的新闻纸底，上方一个几乎顶到边的衬线大标题，字距压得很紧、行距也挤，标题下一道粗一细的双线，再往下分成三栏，栏间一条竖细线，栏内是密排的小字块，通篇只有黑白
- 适合：深度报道片头、播客封面、观点类短视频、书评与影评卡
- 关键词：报纸、衬线大标题、多栏、黑白、密排

## 风格提示词

用代码（Canvas 2D）画一段「Broadside」风格的动画，16:9，30fps，5 秒。

画面规则：
- 纸底 #f4f1e8，边缘压 8% 的 #ddd6c4 做旧，允许几点随机霉斑（alpha 0.08）
- 只用黑 #1a1a1a 一色，灰阶靠 0.55 / 0.3 / 0.15 三档 alpha 模拟油墨深浅
- 报头双线：粗 4px + 细 1px，间隔 3px，横贯版面宽度，距上边 96px
- 正文三栏，栏宽相等、栏间 1px 竖线（alpha 0.3）；每栏文字用 2px 高灰条模拟（行距 9px）
- 大标题衬线字体，字号 132、字距 -3px、行距 0.9，允许跨两行并轻微出血到边

动画节奏：
- 0-1.2s：纸底铺开，报头双线从左端拉到右端（scaleX 0→1）
- 1.2-2.6s：大标题逐行「印」上——每行用裁剪区从上向下揭开，像被压印
- 2.6-3.8s：栏间竖线自上而下画出，三栏文字条按行依次出现（每行 0.03s）
- 3.8-5s：整体轻微放大 1.03 并左移 8px，模拟镜头贴近，停住

技术要点：
- 大标题揭开用 `ctx.save(); ctx.beginPath(); ctx.rect(x, y, w, h*t); ctx.clip();` 画字再 `restore`
- 文字条不要真排文字（会因字体缺失崩版），用 `fillRect` 灰条，只要密度节奏对就成立
- 双线用两次 `fillRect` 而不是 `stroke`，端点才能做到方齐、无半像素模糊
