# H7 Cartesian

- 分类：H 现成版式 · 坐标图版式
- 长什么样：近乎纯白的画布上铺一层 40px 方格的浅灰坐标系，横竖轴线略深；一条蓝色趋势线斜穿画面，线上挂着几个实心圆点，每个点向下垂一条虚线到横轴，旁边标着数值，像被抽出来的一页图表
- 适合：数据新闻、增长与留存讲解、课程里的一页原理图、投资与效率类内容
- 关键词：坐标网格、数据点、趋势线、留白、理性

## 风格提示词

用代码（Canvas 2D）画一段「Cartesian」风格的动画，16:9，30fps，6 秒。

画面规则：
- 底 #fbfbfa，网格 1px #dedede、间距 40px；轴线用 #9a9a9a、1.5px 加粗
- 趋势线 #2b6cb0、2.5px，`lineCap='round'`，允许一点轻微的手绘感（不用完全笔直）
- 数据点：外圈 r=7 实心 #2b6cb0，内圈 r=3 白 #fbfbfa，形成同心环
- 每个点向下一条 1px 虚线（dash 4/4，alpha 0.4）落到横轴，数值 12px #444 标在点右上方
- 画面左上留 120px 空白放一个 28px 小标题，其余全部留给图

动画节奏：
- 0-1.2s：网格从中心向外扩展（以中心为原点放大 0.6→1，同时透明度 0→1）
- 1.2-3.5s：趋势线从左向右「画」出来（`lineDashOffset` 递减），笔尖带一个 r=4 的光点
- 3.5-5s：数据点按 x 顺序逐个弹出（r 7→10→7），虚线同时从点落到轴
- 5-6s：数值淡入，趋势线末端延长 20px 并渐隐，静止

技术要点：
- 折线长度用 `ctx.setLineDash([L, L])` + `lineDashOffset` 从 L 减到 0，比逐段拼接干净
- 网格用双层 `for` 画，但把 `beginPath` 放在循环外、只 `stroke` 一次，性能差别很大
- 点弹跳不要用物理，`r = 7 + 3*Math.sin(t*Math.PI)` 在 0.25s 内跑完即可
