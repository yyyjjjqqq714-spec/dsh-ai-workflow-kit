# K20 剪纸

- 分类：K 卡通画风 · 纸艺手作
- 长什么样：整张中国红纸刻出连绵镂空，边缘是刀刻的锯齿与圆角交替，纸背一层浅影托离底色；构图对称留白，四周环绕云纹花草，颜色只有红、米白、一点墨黑
- 适合：节庆片头、非遗民俗讲解、国潮短片、故事动画的场景切换
- 关键词：剪纸、镂空、红纸、刀味、对称、窗花

## 风格提示词

用代码（Canvas 2D）画一段「剪纸」风格的动画，16:9，30fps，7 秒。

画面规则：
- 底色 #f7f1e3（米白宣纸），叠 opacity 0.02 的纸纤维噪点
- 主色 #c8102e（中国红）占画面 55%，辅色 #1f1a17（墨黑）只用于点缀与投影
- 所有红色形状用「外轮廓 + 内挖孔」一次性填充：`ctx.fill('evenodd')`，孔洞只用圆、月牙、花瓣三种基础形
- 边缘做「刀味」：每 6-8px 插入 ±1.2px 偏移，转角留 1px 直角缺口
- 红纸下压 #000000、opacity 0.12、偏移 (4,6)、blur 8 的投影，纸才有厚度

动画节奏：
- 0-1.2s：左右两扇红纸从画外合拢（translateX ±120→0，easeOutQuint），中间留 2px 缝
- 1.2-4s：镂空从中心向外「刻」出——孔洞半径 0→目标值，easeOutBack 带 6% 过冲，像刀尖顶穿纸面
- 4-5.6s：纸面轻微旋转 -1.5°→0°，投影同步偏移，像被手抚平
- 5.6-7s：四周云纹依次亮起（叠加 #ff5a5f、opacity 0.25），静止收尾

技术要点：
- 挖孔用 `arc` 拼 path 后 `fill('evenodd')`；别用 destination-out 擦除，否则投影一起被擦掉
- 刀味抖动写成 `jitter(points, amp)`，每条路径每帧用固定 seed，避免乱颤
- 投影用 `shadowColor`/`shadowBlur`/`shadowOffsetX` 一次设好，画完立刻清零，防止污染后续图形
