# K23 拼贴

- 分类：K 卡通画风 · 混合材料
- 长什么样：牛皮灰底板上钉着十几块剪报碎片——报纸白、黑条、红块、蓝照片，边是手撕的毛边，每块歪 2-3°，接缝贴着半透明胶带；信息是碎的、重叠的、故意对不齐
- 适合：蒙太奇、纪录片插叙、独立杂志风片头、音乐短片
- 关键词：拼贴、剪报、撕边、胶带、错位、混合材料

## 风格提示词

用代码（Canvas 2D）画一段「拼贴」风格的动画，16:9，30fps，7 秒。

画面规则：
- 底板 #d8d2c4 灰纸，碎片色 #f2e9d8 报纸白、#2b2b2b 黑条、#c94f3d 红块、#3a5a78 蓝照片
- 每块碎片 rotation 在 -3°~3° 之间随机，位置故意错开 4-8px，绝不对齐网格
- 撕边：沿矩形四边每 5px 抖动 ±2px，四个角各缺一小口；黑条用纯 `fillRect` 不撕边，故意形成对比
- 胶带 #e8dfc0、opacity 0.72、宽 26px、长 90px，压在碎片接缝上，两端各有一个小直角

动画节奏：
- 0-2.4s：碎片间隔 0.12s 从画面外甩入（translate + rotate 60°→目标角，easeOutBack 过冲 12%）
- 2.4-4s：胶带逐条「啪」地按下——scaleY 0→1 用 0.12s 的 easeOutQuart，同时压暗 4%
- 4-5.5s：三块关键碎片被「抽走」再放回，位置偏移 6px，模拟手工挪动
- 5.5-7s：整体轻微推近 4%（scale 1→1.04），定格

技术要点：
- 每块碎片包成 `{x, y, rot, path}` 对象，绘制时 `save / translate / rotate / restore`，不要直接改坐标
- 撕边路径用固定 seed 的伪随机生成一次并缓存成 `Path2D`，别每帧重算
- 胶带高光是一条 opacity 0.35 的白色斜线，方向统一 45°，这是「塑料膜」的辨识点
