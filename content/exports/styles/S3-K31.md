# K31 平铺整理

- 分类：K 卡通画风 · 俯拍静物
- 长什么样：正俯视的木桌面，十几件工具与物件按 4×3 网格摆得整整齐齐，间距一致；每件东西有一层贴边的短阴影，色系统一在莫兰迪调，像博主拍的开箱平铺图
- 适合：开箱与工具展示、装备清单、生活方式短片、教程物料页
- 关键词：平铺、俯拍、网格、整齐、道具、莫兰迪

## 风格提示词

用代码（Canvas 2D）画一段「平铺整理」风格的动画，16:9，30fps，7 秒。

画面规则：
- 底色 #d9c7ac 木桌，叠 opacity 0.05 的木纹长条（宽 2px、长度随机）
- 物件色板：#2f4858 深蓝、#e07a5f 陶红、#f2cc8f 米黄、#81b29a 灰绿，每件只用一色 + 一个暗 12% 的侧面
- 每件物件带硬阴影：offset (3,3)、无 blur、#000000、alpha 0.12；物件之间最小间距 32px
- 构图严格 4 列 × 3 行，单元 260×140，整体在画面内留 60px 边距

动画节奏：
- 0-2.4s：物件按「从左到右、从上到下」逐个放到桌上（从上方 40px 落下 + rotate 8°→0，easeOutQuad，每件 0.15s）
- 2.4-4.2s：放完后整体下压 1px 再回弹，阴影同步从 0 长到全尺寸
- 4.2-5.8s：镜头缓慢推近到 1.06（中心偏左上），三件重点物件被一圈手绘感白线框住
- 5.8-7s：白线框内的物件单独抬起 6px，投影变大，定格

技术要点：
- 阴影用 `rgba(0,0,0,0.12)` 偏移复制同一路径，不要 shadowBlur——硬阴影才是贴纸平铺感
- 摆放位置写成 `grid(i)` 返回中心点，物件内部坐标一律以中心为原点
- 推近用 `ctx.translate + ctx.scale` 包住整组绘制，别逐个改坐标
