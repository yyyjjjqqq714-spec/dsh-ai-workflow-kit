# K35 旧学院风

- 分类：K 卡通画风 · 复古印刷
- 长什么样：牛皮纸色的旧纸，四角压暗，纸上只印暗绿与酒红两色，外加少量金线；中央是圆形徽章，双线外环 + 星形 + 宽字距衬线字，像一枚校徽
- 适合：讲历史与传承、学院教育、精品咖啡与酒类品牌、复古书封
- 关键词：旧学院、牛皮纸、徽章、衬线、暗绿、复古

## 风格提示词

用代码（Canvas 2D）画一段「旧学院风」风格的动画，16:9，30fps，8 秒。

画面规则：
- 底色 #e8dcc3 牛皮纸，叠 opacity 0.06 的噪点与四周 opacity 0.12 的暗角；主色 #1f3a2e 暗绿、#7a2e2e 酒红、#b08d57 金
- 徽章：外环 r=120 双线（3px + 1px，间距 8px），内环 r=96，中心一枚 5 角星与三条横线
- 文字全部衬线体（Georgia / 宋体），字距 3px，字号不超过 28px
- 只用三种颜色；金线只用于装饰线，不做大面积填色

动画节奏：
- 0-1.4s：纸面从 1.06 缩到 1（easeOutQuart），暗角同步加深
- 1.4-3s：徽章「盖章」落下——scale 1.25→1 用 0.18s，伴随 2px 抖动与一次 alpha 闪烁
- 3-4.6s：外环双线沿圆周生长（dash），星形从中心放大，装饰线向左右展开
- 4.6-6.2s：下方两行衬线字逐字浮现（每字 0.08s），字距从 6px 收到 3px
- 6.2-8s：整体上移 4px，纸纹噪点闪一下，静止

技术要点：
- 纸张纹理用离屏 canvas 生成 512×512 噪点后 `createPattern` 平铺，配 `multiply` 混合
- 盖章抖动用 `Math.sin(t * 80) * (1 - p) * 2`，p 是盖章进度，结束必须归零
- 衬线字设 `ctx.font = '600 24px Georgia, "Songti SC", serif'`，中文靠回退到宋体
