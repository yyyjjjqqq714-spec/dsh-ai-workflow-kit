# K4 极简线条小人

- 分类：K 卡通画风 · 角色风格
- 长什么样：纯白底上一条 2.5px 黑线画的人——圆头、一道弧背、两条直腿、两条摆臂，没有五官也没有衣服；脚下一条地平线，其余全是空白，留白率 85% 以上
- 适合：概念讲解、情绪隐喻、极简片头、播客片头
- 关键词：单线、极简、留白、黑白、走路循环

## 风格提示词

用代码（Canvas 2D）画一段「极简线条小人」风格的动画，16:9，30fps，6 秒。

画面规则：
- 底色 #ffffff，不铺任何纹理，画面只存在于中下三分之一
- 唯一颜色 #1a1a1a，lineWidth 2.5，`lineCap` / `lineJoin` 均为 round
- 人物结构：头 r=26 圆，躯干是一条从颈到胯的二次贝塞尔，双腿双臂各一条直线，总高 240px
- 地平线在 y=620，长 200px 居中，两端 alpha 渐隐
- 允许一行 #1a1a1a 手写体短句压在地平线下方（字号 22，字距 4），除此之外不加任何元素

动画节奏：
- 0-1.6s：从头顶开始逐笔描出（头 → 躯干 → 腿 → 臂，每笔 0.35s），像有人随手画
- 1.6-4.6s：进入走路循环，髋部起伏 6px，双腿交替摆 ±18°，双臂反向摆 ±22°
- 4.6-5.6s：人物向右走出画面（translateX +40%），只留地平线
- 5.6-6s：地平线从中间向两端缩到 0，纯白收尾

技术要点：
- 描线用 `ctx.setLineDash([len, len])` 配 `lineDashOffset` 从 len 递减到 0，长度先 `getTotalLength()` 量
- 走路靠相位驱动：`legA = Math.sin(phase)*0.32`，另一条腿取反相，不要写两套关键帧
- 全程禁止 fill 人物，一旦填色就不再是「线条小人」
