# Z14 彩铅手绘

- 分类：Z 中国风 · 彩铅手绘
- 长什么样：轮廓线不是一根，是三根微微错开的细线叠在一起，看起来毛茸茸的；颜色靠 45° 的短笔触一层层叠上去，纸面的颗粒从颜色缝里透出来；整体偏暖，像旧速写本上的一页
- 适合：手作与生活方式品牌、儿童绘本动画、课程插图、温暖叙事短片
- 关键词：彩铅、毛糙线条、纸纹、叠色、颗粒

## 风格提示词

用代码（Canvas 2D）画一段「彩铅手绘」风格的动画，16:9，30fps，8 秒。

画面规则：
- 纸底 #fbf6ec，全画面盖一层噪点 pattern（1px 点、alpha 0.06），这是纸纹
- 四支主色：#e07a5f（赭橙）、#81a684（灰绿）、#4f6d8c（蓝灰）、#e6c15a（土黄），不许出现纯正红蓝
- 每条轮廓画 3 遍：`(0,0)`、`(+1.5,-1)`、`(-1,+1.2)` 三个偏移，每遍 alpha 0.45，形成毛边
- 填充不用实色，用 45° 短笔触（长 8-14px、宽 2px、间距 3-5px），密度决定明暗：亮=间距 6，暗=间距 2
- 主体：一个捧杯的人 + 一株植物，全部圆角化，没有一条直线

动画节奏：
- 0-2.5s：轮廓三遍线依次描出（每遍 0.6s），像手在反复找形
- 2.5-5s：叠色从浅到深铺三层，笔触方向一致（都 45°），每层 alpha 0.35
- 5-6.5s：局部加亮——杯口、脸的高光用白笔点两笔，笔触更短
- 6.5-8s：纸纹噪点整体轻推 2px（模拟翻页），画面定住

技术要点：
- 短笔触用 `ctx.translate` + `rotate(45°)` 后画 `fillRect(0,0,12,2)`，比逐点 `lineTo` 快
- 三层线要共用同一路径对象（`Path2D`），只改 `setTransform` 偏移，避免形状抖动
- 纸纹 pattern 用离屏 canvas 预生成 64×64，`createPattern(..., 'repeat')` 全屏铺一次即可
