# Z15 温暖水彩科普卡

- 分类：Z 中国风 · 水彩科普卡
- 长什么样：底上是几团杏粉、浅绿、淡黄的水彩晕染，边界模糊、互相渗色；上面浮着 2-3 张白色大圆角卡片，卡片里有圆形图标和两条文字占位条，整体像一本手账里的知识页
- 适合：轻知识科普、健康与育儿内容、课程章节卡、社区运营图
- 关键词：水彩、科普卡、圆角卡片、柔和、留白

## 风格提示词

用代码（Canvas 2D）画一段「温暖水彩科普卡」风格的动画，16:9，30fps，8 秒。

画面规则：
- 纸底 #fdfaf4，四周留 56px 安全边距，卡片绝不越界
- 水彩四团：#f7c8b0（杏）、#cfe0c3（浅绿）、#f6e0a8（淡黄）、#bcd4e6（浅蓝），各自 blur 30px，`multiply` 叠加
- 卡片纯白 #ffffff，圆角 20px，描边 1px #eee7dc，阴影 `rgba(120,100,80,0.12) 0 8px 24px`
- 卡片内：圆形图标底（r=22，用对应水彩色 alpha 0.35）、标题条（圆角 4px、高 10px、宽 60%）、正文条（高 6px、两行、宽 82%/64%）
- 全片无黑色，最深只到 #4a4239，字重中等，不做粗黑标题

动画节奏：
- 0-2s：四团水彩从中心向外晕开（半径 0→200，同时 blur 由 0 增到 30）
- 2-3.5s：三张卡片依次上浮（translateY 24→0，间隔 0.15s，easeOutCubic）
- 3.5-5.5s：图标圆底弹出，文字条从左向右展开（scaleX 0→1，transform-origin 左侧）
- 5.5-8s：水彩层极缓漂移（6px/s），卡片轻微 2px 呼吸，定住

技术要点：
- 水彩 blob 用 `beginPath` + 12 个随机半径的 `arc` 连成不规则的圆，再 `filter='blur(30px)'` 铺
- 卡片阴影别用 `shadowBlur` 逐帧算，改成先画一层半透明模糊矩形，性能差 5 倍
- 文字条用 `roundRect`（Safari 需自行 polyfill 或用 arc+lineTo），半径 4px 不要写成 0
