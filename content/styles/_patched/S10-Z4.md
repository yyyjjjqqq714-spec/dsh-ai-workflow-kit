# Z4 山水

- 分类：Z 中国风 · 山水
- 长什么样：五层远近山脊由淡到浓叠出纵深，山形是平缓的折线不是尖峰，山脚被横向云雾切断；水面留大片空白，只有一叶小舟和一枚细小人影，整体偏青灰
- 适合：旅行与地理纪录片、茶叶与民宿品牌、冥想音频背景、文旅宣传片
- 关键词：山水、层叠、云雾、小舟、空气透视

## 风格提示词

用代码（Canvas 2D）画一段「山水」风格的动画，16:9，30fps，8 秒。

画面规则：
- 天空 #e6ece6 渐变到地平 #dfe6df；水面 #eef1e9
- 五层山由远及近取色：#a8b6b2 → #8b9c98 → #6d7f7b → #4e5f5b → #33413d，远山几乎融进天里
- 山形一律用 6-10 个点的折线，缓坡为主，允许一处陡崖；山顶不画树，只在下缘给 3-4 条短竖线当林
- 云雾是 4-6 条横向长条（宽 400-900、高 24-40），#f5f2e8、alpha 0.55，边缘 blur 12px
- 小舟：3px 弧线当船底 + 一竖当桅 + 一个 r=2 的点当人，位置压在第三层山脚的水线上

动画节奏：
- 0-2.5s：远山从上方 20px 处淡入并落位（最远层先出，每层隔 0.4s）
- 2.5-5s：云雾自左向右缓慢平移（速度 6px/s，循环错相），逐层遮住山脚
- 5-7s：小舟从右侧 1/4 处驶入，水平位移 120px，船身随波浪起伏 ±2px
- 7-8s：最前一层山脚压暗 10%，定格收尾

技术要点：
- 每层山用 `ctx.save()` 后平移不同速度做视差，位移比 1 : 0.75 : 0.55 : 0.35 : 0.2
- 云雾用 `createLinearGradient` 横向透明渐变 + `filter='blur(12px)'`，直接 `fillRect` 即可
- 水面加 5 条 1px 横线（alpha 0.12，长度 60-140 随机），避免大片死白
