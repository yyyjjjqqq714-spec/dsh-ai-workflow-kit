# K2 Q 版

- 分类：K 卡通画风 · 角色风格
- 长什么样：二头身小人，头占全身 55%，圆脸配两只大眼（黑底 + 两颗白高光）；身体是一颗豆形，四肢是四根短香肠；配色是奶粉、雾蓝、奶油黄这类降饱和马卡龙
- 适合：个人 IP 形象、情绪表情、App 引导页、口播配图
- 关键词：Q 版、二头身、马卡龙、大眼睛、弹跳

## 风格提示词

用代码（Canvas 2D）画一段「Q 版」风格的动画，16:9，30fps，6 秒。

画面规则：
- 底色 #fdf6ec（奶油白），地面阴影是 #e8dccb 椭圆（rx 90 / ry 14，alpha 0.5）
- 主色 #ffd9e2（奶粉）、#a8d8ea（雾蓝）、#ffe6a7（奶油黄），单帧不超过 3 色
- 角色：头 r=150 正圆；身体用两段贝塞尔画成豆形（宽 110 / 高 130）；四肢 4 根 lineWidth 22 的短管
- 眼睛两个 #2b2b2b 椭圆，每只叠两颗 #ffffff 高光（一大一小），腮红 #ffb3c1 alpha 0.35
- 全身统一描边 #3d3a37 3px，不要投影、不要渐变

动画节奏：
- 0-1.2s：角色从画面上方落入，触地时压扁 12%（scale 1.12/0.88）再回弹
- 1.2-3.2s：身体以 1.4s 周期呼吸（scaleY 1→1.03），每 2.4s 眨一次眼（眼睑下扫 90ms）
- 3.2-4.6s：右手抬起挥手，前臂绕肘关节 -35°→+15° 摆两次
- 4.6-6s：头顶错峰弹出三颗小爱心（scale 0→1.2→1，间隔 0.12s），角色轻微左右晃

技术要点：
- 落地回弹用 easeOutBack：`1 + 2.2*Math.pow(t-1,3) + 1.2*Math.pow(t-1,2)`
- 眨眼不要缩放眼睛，用同色矩形从上往下裁切，配 `ctx.clip()`
- 四肢用 `lineCap='round'` 的 stroke，关节处补同色圆，接缝才看不出
