# K33 地铁图

- 分类：K 卡通画风 · 信息图表
- 长什么样：白底上四条彩色线路，全是 45° / 90° 折线，转角圆润；站点是白底彩色描边的圆点，换乘站是白底黑框的大圆；线路粗细一致，颜色高饱和，站名小而清晰
- 适合：讲流程 / 路线 / 依赖关系、产品架构、旅行与交通内容、用户增长路径
- 关键词：地铁图、线路、站点、45°、彩色、信息图

## 风格提示词

用代码（Canvas 2D）画一段「地铁图」风格的动画，16:9，30fps，7.5 秒。

画面规则：
- 底色 #fafafa，线路色 #e63946 红、#2a9d8f 青、#457b9d 蓝、#f4a261 橙，lineWidth 10、圆头端点
- 转角只能是 45° 或 90°，`lineJoin = 'round'`，圆角半径不超过 12px
- 站点：白底 + 同线路色描边 3px、半径 7；换乘站白底 + #1d1d1d 描边 3px、半径 11
- 站名用 12px 无衬线，沿线路水平或垂直排，始终在线的上方或右侧

动画节奏：
- 0-2.8s：四条线路从各自起点沿路径生长（dash 从全长收到 0，每条错开 0.3s）
- 2.8-4.4s：站点在线路经过时弹出（scale 0→1.2→1，0.18s），换乘站最后出现并闪一下
- 4.4-6s：一条 3px 白线沿主线路再走一遍，像「当前进度」
- 6-7.5s：站名逐条淡入，整体平移 8px 收尾

技术要点：
- 先把线路算成点数组、用 `Path2D` 一次建好；生长用 `setLineDash([total, total])` + `lineDashOffset`
- 站点别只画在端点，要画在折点与每段中点，否则线看起来是空的
- 换乘站的黑色描边必须在彩色线之后画，否则会被线路盖住
