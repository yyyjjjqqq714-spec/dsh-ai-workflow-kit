# K34 赛博霓虹

- 分类：K 卡通画风 · 数字未来
- 长什么样：近黑的深紫底，霓虹管是饱和度极高的粉、青、紫，每根管子两层辉光；背景是透视网格地平线，空气里飘着细小光尘，像雨夜的电子招牌
- 适合：未来科技、AI 与硬件发布、电音 / 游戏预告、夜间城市题材
- 关键词：赛博、霓虹、辉光、暗底、网格、粉紫

## 风格提示词

用代码（Canvas 2D）画一段「赛博霓虹」风格的动画，16:9，30fps，7.5 秒。

画面规则：
- 底色 #0a0616，霓虹色 #ff2e88 粉、#00e5ff 青、#b026ff 紫；地面网格 #2a1650
- 每根霓虹线画三遍：外层 lineWidth 14 + shadowBlur 28 + alpha 0.25，中层 6 + alpha 0.6，内芯 2 纯白
- 全局叠一层扫描线：每 4px 一条 #000000、alpha 0.12 的横线，再加 0.06 的暗角 vignette
- 网格地面：视平线在画面 62% 处，纵向线向灭点收敛，横向线按指数间距向观众靠近

动画节奏：
- 0-2s：地平线先亮起（一条 2px 青线从中心向两侧延伸），随后网格向观众滚动
- 2-4.5s：主体图形逐笔点亮，带 3 次随机 flicker（alpha 0.3↔1，间隔 60ms）
- 4.5-6s：粉色光晕呼吸式放大（shadowBlur 28→44→28，周期 1.2s），光尘向上飘
- 6-7.5s：整体轻微色差抖动（红蓝通道各偏移 1px），定格

技术要点：
- 辉光靠 `shadowColor + shadowBlur`，画完必须 `shadowBlur = 0`，否则后面所有元素都会发光
- 扫描线用离屏 canvas 预生成一次图案，`createPattern` 平铺，别每帧画几百条线
- 网格滚动用 `offset = (t * 60) % spacing` 的模运算，保证首尾无缝
