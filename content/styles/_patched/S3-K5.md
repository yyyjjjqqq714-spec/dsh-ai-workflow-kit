# K5 孟菲斯扁平人

- 分类：K 卡通画风 · 角色风格
- 长什么样：几个无脸小人，头是纯色圆，身体是圆角矩形或梯形，手臂细得像面条、末端接一只夸张的大手掌；背景飘着半圆、波浪线、圆点阵和 Z 形折线，构图左下重、右上轻
- 适合：企业宣传、团队协作主题、招聘页、SaaS 功能说明
- 关键词：Corporate Memphis、无脸、面条手臂、大手掌、漂浮几何

## 风格提示词

用代码（Canvas 2D）画一段「孟菲斯扁平人」风格的动画，16:9，30fps，7 秒。

画面规则：
- 底色 #f3efe7（亚麻），所有元素无描边无阴影
- 主色 #3b6ea5（雾蓝）、#e2703a（陶土橙）、#7fae8b（鼠尾草绿）、#f0c05a（芥末黄），肤色另给 #f2c6a0 / #8d5b3f
- 人物：头 r=34 实心圆且无五官，躯干是 88×120 圆角矩形（r=40），手臂 lineWidth 6、手掌 r=16 椭圆，腿 lineWidth 7
- 背景漂浮物只四类：半圆（r 60 切一半）、两段波浪线（lineWidth 8）、直径 18 的实心圆点阵、Z 形折线
- 三个人物错落三个高度，刻意打破对称

动画节奏：
- 0-1.2s：三个几何漂浮物从左下角错峰滑入（translateX -80→0，间隔 0.15s）
- 1.2-3s：三个人物从底部升起（translateY 60→0，easeOutCubic），各自落在不同高度
- 3-5.5s：所有漂浮物开始独立漂浮——半圆自转、圆点上下 ±12px、波浪线横向平移，相位全不同
- 5.5-7s：中间那人抬起面条手臂做指向手势，手掌放大到 1.15 倍，静止收尾

技术要点：
- 漂浮统一写成 `y = base + Math.sin(t*speed + phase) * amp`，每个元素给不同 speed / phase，千万别同步
- 面条手臂用二次贝塞尔，控制点抬高做出柔软弧度，`lineCap='round'`
- 圆角矩形用 `roundRect`，半径给到高度的一半才像人体，用 `rect` 会变成方块人
