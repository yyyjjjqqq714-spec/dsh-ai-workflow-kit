# K8 绘本

- 分类：K 卡通画风 · 叙事插画
- 长什么样：圆到几乎没有棱角的角色和树，每个形状外面留一圈奶白空隙；整体是奶茶色系配鼠尾草绿；纸面铺着细密颗粒，像印在粗糙绘本纸上
- 适合：儿童故事、亲子内容、温暖品牌片、睡前故事
- 关键词：绘本、圆润、纸纹、奶白间隙、暖调

## 风格提示词

用代码（Canvas 2D）画一段「绘本」风格的动画，16:9，30fps，7 秒。

画面规则：
- 底色 #f6ecd9（旧纸米色），叠 3000 个 1px 随机点的颗粒（alpha 0.05）
- 主色 #e8a87c（杏仁橙）、#85b7a0（鼠尾草）、#d9c27e（麦黄）、#c98b7a（陶粉）
- 套印留白：先用 #f6ecd9 描 8px 边，再画填充，形与形之间自然留出空隙
- 角色：头 r 70 圆 + 梯形身体，眼睛两个 #4a3f35 小圆点，嘴一条短弧；树冠用三层圆叠成云朵状
- 地平线在 y=520，近景大远景小，允许一棵树出血裁掉一半

动画节奏：
- 0-2s：远山与天空淡入（alpha 0→1，1.2s），纸纹同时显现
- 2-3.6s：树从根部向上长出（scaleY 0→1，带 6% 回弹），树叶逐个弹出
- 3.6-5.4s：小人从右侧走进来（每步 0.5s），身体以 3° 幅度左右摇，头发一颠一颠
- 5.4-7s：整幅上下浮动 ±4px（周期 2s），四角渐暗 8%，收尾

技术要点：
- 颗粒预生成一次离屏 canvas 用 `createPattern` 复用，每帧重新随机会闪
- 套印留白靠「粗描底色 → 填充 → 补一圈本色」三步，不是加描边线
- 柔和感来自 `globalAlpha` 与圆角，不要用 blur；绘本的边是实的
