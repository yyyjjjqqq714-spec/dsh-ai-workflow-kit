# M26 副歌段落 · 画面爆炸

> （原库该条目为空，此处为补全内容）

- 分类：M 动态风格 · 节奏和快剪类
- 长什么样：前两秒压得很低很闷，颜色发灰、画面收窄；副歌一进，画面从中心炸开，色块、圆环、字形碎片一起往外冲，四拍之内炸完就定住。
- 适合：歌曲副歌、视频的转折高潮、"忍了很久终于说出来"的情绪释放
- 关键词：副歌、爆炸、强弱对比、色块、卡点、冲击

## 风格提示词

用代码（Canvas 2D）画一段「副歌段落 · 画面爆炸」风格的动画，16:9，30fps，5 秒。

画面规则：
- 主歌段底色 #1b1b1f，主色压到 #6b6f78，暗角收到画面 60%，元素只占中心 25%
- 副歌段底色翻成 #0d0d0d，三色上齐：#ff3b30、#ffd23f、#2ee6a8，允许纯色平涂
- 爆炸元素只准五类：色块、圆环、星芒、光条、字形碎片，总数不超过 40 个
- 字形碎片从一句口号里切成六块，每块单独飞
- 只许两个 shockwave 环（6px 与 2px），不要光晕、不要粒子

动画节奏：
- 0-2s：中心一个圆缓慢脉动，字只露一半，色压到最低
- 2-2.1s：drop 前所有元素缩到 0.85，屏住一拍
- 2.1-2.6s：爆炸，40 个元素按极坐标冲出画外，两个环扩散
- 2.6-3.4s：元素原地每 3 帧抖一次，速度降到 8%
- 3.4-5s：全体内收 12%，停成一张满版构成图

技术要点：
- 元素参数 {angle, dist, size, color, delay} 预先算好，爆炸时只插值不新建对象
- 120bpm 每拍 0.5s，爆炸必须落整拍：`hit = Math.round(t / 0.5) * 0.5`
- `easeOutExpo = 1 - Math.pow(2, -10 * p)`，冲出后立刻收速才有"撞墙"感
- 主歌到副歌的对比只靠暗角半径和饱和度两个数值，别用滤镜硬堆
